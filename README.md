# Mandibular Canal Segmentation and Continuity Refinement
In this work, we present a novel mandibular canal segmentation pipeline for 3D CBCT scans. We first train a supervised 3D nnU-Net segmentation model using a progressive, model-assisted annotation strategy. We then apply a training-free refinement step that restores anatomical continuity to the model's predictions by tracing minimum-cost paths through the network's own probability field to bridge genuine gaps, while a conservative safety rule flags canals that are truly disrupted by pathology instead of bridging them.
